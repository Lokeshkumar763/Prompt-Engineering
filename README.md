# Prompt Engineering

This repository contains my Prompt Engineering Reports and tasks that are completed as part of my Generative AI Internship.

## Experiments

The report covers three practical prompt engineering experiments:

1. **Zero-Shot vs Few-Shot Prompting**

   * Sentiment classification
   * Comparison of accuracy and consistency

2. **Direct vs Step-by-Step Prompting**

   * Multi-step mathematical problem
   * Comparison of reasoning and output clarity

3. **Structured JSON Output**

   * Information extraction
   * JSON schema and format validation across 5 test inputs
